Red Letter

News from different sources, brought together in one clear story.

Personal project · June to July 2026

Visit Red Letter ↗View the code ↗

Why I built it

Reading the news had become a routine of opening 10 or 12 tabs to understand a single story. Most publications repeated the same facts, while the useful differences were scattered across their coverage.

I built Red Letter to handle that comparison for me. It finds articles about the same event and turns them into one short summary that shows what the sources agree on and where they differ.

How it works

Red Letter checks 46 feeds from 22 publishers and processes more than 1,000 articles each week.

It collects new articles, extracts the readable content, and compares each story with the rest. Articles covering the same event are grouped together before a summary is written.

A claim must appear in at least two sources before Red Letter includes it. If publishers report different numbers, dates, or details, the summary points out the difference instead of picking a side.

Getting the summaries right

The first version relied on a broad prompt asking the AI to write an unbiased summary. The results were inconsistent. Some summaries used dramatic language, added filler, or returned information in the wrong format.

I replaced that prompt with specific rules for sourcing, tone, and structure. Every response follows the same format, avoids sensational wording, and separates confirmed facts from disagreements between sources.

A bug that took some digging

At one point, the pipeline kept crashing after processing larger groups of articles. I first suspected Gemini rate limits because the failures appeared during the embedding stage.

After tracing the data through the full pipeline, I found that some Playwright browser sessions were staying open. They slowly used up the available memory and sent incomplete data into the clustering step.

Closing every browser session after each publisher run fixed the memory leak. I also split embedding requests into smaller batches, added retries, and stopped invalid data before it reached clustering. The system has maintained 99.8% uptime since those changes.

What came out of it

Red Letter cuts a 20-minute search across several news sites down to a two-minute read. Readers get the main facts, links to the reporting, and a clear note when sources disagree.
